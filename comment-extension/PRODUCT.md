# Comments Analyzer - Product Definition

## Users
- 社交媒体内容分析师
- 研究学者
- 运营人员
- 数据科学家

## Product Purpose
Chrome 扩展工具，用于在 Weibo/X/Reddit 等平台拦截 API 请求并解析评论数据，提供可视化分析报告。

## Brand Register
product

## Design Goals
- **专业性**：数据分析工具，强调清晰、准确的信息呈现
- **高效性**：快速操作，减少鼠标移动路径
- **信息密度**：在有限空间内展示尽可能多的数据
- **可扩展性**：支持多平台评论格式解析

## Tone & Voice
- 简洁直接的 UI 文案
- 无冗余装饰，功能优先
- 技术感的视觉语言

## Anti-References
- 避免 SaaS-cream 风格（过度圆润、渐变）
- 拒绝玻璃拟态装饰性使用
- 不使用 hero-metric 模板
- 避免 em dash 标点
